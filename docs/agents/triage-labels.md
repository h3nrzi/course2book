# Triage Labels

The skills use five canonical triage roles. For this local Markdown tracker, record the corresponding string on the issue's `Status:` line.

| Canonical role | Tracker status | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an unattended agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill mentions a triage role, use its tracker status from this table. Wayfinding claim and resolution states are defined separately in `issue-tracker.md`.

Edit the Tracker status column to change the vocabulary later.
