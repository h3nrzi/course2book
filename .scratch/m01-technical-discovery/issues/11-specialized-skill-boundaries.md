# Choose the minimal specialized Agent Skill responsibilities

Type: grilling
Labels: wayfinder:grilling
Mode: HITL
Blocked by: 10
Parent: [Technical Discovery for M01 — Content Production](../map.md)
Requirements: P18, P24–P26; C7; AC-M01-09

## Question

What is the smallest coherent set of specialized Agent Skills that owns M01's responsibilities and can be invoked independently without requiring full-lesson or full-book regeneration?

Compare meaningful responsibility groupings rather than assuming one skill per artifact or importing the installed discovery skills as production components. For each proposed responsibility establish its intent, input and output contracts, allowed changes, ownership of checks, observable completion, and handoff to the next responsibility. Account for preparation, analysis, authorship, research, example verification, QA, revision, and approval support without requiring a separate skill for every verb.

Use runtime evidence and agreed artifact and QA contracts to test whether the proposed boundaries are practical. Resolve packaging and responsibility boundaries, with alternatives and trade-offs. Do not write SKILL.md files, detailed prompts, or implementation tasks.

## Dependency rationale

- [Choose quality assurance evidence and finding semantics](10-quality-assurance-evidence.md): QA evidence and finding semantics establish review responsibilities that skill packaging must accommodate.

Runtime evidence and artifact contracts are already prerequisites through QA and must also inform the skill boundaries.
